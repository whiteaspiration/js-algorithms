## Конспекты

### Git для новичков (часть 1)

- **Коммиты** - это что то вроде сохранений в играх, которые помогают зафиксировать кусок работы. Очень полезная штука
- **Ветки** - позволяют экспериментировать, по сути, в изоляции. Работаешь над своей задачей в своей ветке, не боясь случайно сделать баги в основном коде.
- **Команда 'git reflog'** - это вообще самая крутая фича! Оказывается, если даже принудительно удалить ветку со всеми файлами, git не стирает коммиты сразу, давая возможность вернуть потерянную работу обратно к жизни <ins>(в течении 30-90 дней)</ins>.
- **Git и GitHub - разные вещи** - Git работает у тебя на компе локально и хранит историю изменений, а GitHub - это просто сайт, куда ты выгружаешь проект, чтобы сохранить его в облаке или показать ревьюеру.
- **Подготовка через 'git add'** -  Ты сначала отбираешь нужные файлы в специальную зону подбора и только потом делаешь коммит — делаешь финальный «снимок».
