# js-algorithms

Учебный репозиторий: модуль "Алгоритмика".

## Что внутри

- `homework.md` — мои цели на модуль и конспекты статей
- практики и функции для работы со строками появятся по ходу модуля

- `string-utils` — библиотека утилит для работы со строками и их лексикографического сравнения (разработана по метод TDD):
  - `len` - вычисление длины строки
  - `isEqual` - проверка строк на равенство
  - `isNotEqual` - проверка строк на неравенство
  - `isMore` - проверка, больше ли первая строка
  - `isLess` - проверка, меньше ли первая строка
  - `isMoreOrEqual` - проверка, больше или равна первая строка
  - `isLessOrEqual` - проверка, меньше или равна первая строка
